Grid World Robot Simulator

A text-based robot simulation, built in Python, one phase at a time.

Status: Phase 1 of 8 in progress. This is a learning project. The banner above shows the goal, not what exists today.

About

This is one living project. I do not rebuild it from scratch. Every time I finish learning a Python concept, I add it to this same project. So the code, and the git history, show how my understanding grows.

The idea (robot "brain" loop)

The robot repeats three steps again and again:

Sense - look at the world around it
Decide - choose what to do
Act - do it

Rules of this project
Text only. No GUI, no images inside the program.
No pathfinding before Phase 8. Before that, the robot follows simple rules.
Only use concepts I have already learned. Nothing extra.
